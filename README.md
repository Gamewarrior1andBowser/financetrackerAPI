# Personal Finance Tracker

A full-stack personal finance management application designed to help users monitor their financial activity, build healthy spending habits, and make informed budgeting decisions.

The application provides a secure platform for recording income and expenses, organizing transactions into categories, setting monthly budgets, and visualizing spending trends. By combining financial tracking with insightful analytics, the project aims to simplify personal money management through an intuitive and responsive user experience.

---

## Features

- Secure user authentication
- Income and expense tracking
- Custom transaction categories
- Monthly budgeting by category
- Financial dashboard with spending summaries
- Search, filter, and sort transactions
- Financial insights based on spending habits
- Responsive design for desktop and mobile devices

## Database Structure

The application is built around a relational MySQL database consisting of the following core entities:

### Users
Stores account information and authentication credentials.

### Categories
Allows users to organize transactions into income and expense categories.

### Transactions
Records all financial activity including transaction amount, category, date, and type.

### Budgets
Stores monthly spending limits for individual categories and enables budget tracking.

### Financial Insights
Provides generated recommendations and summaries based on user spending patterns.
